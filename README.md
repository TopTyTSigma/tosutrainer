# ToSU! Trainer!

Windows x64 rhythm training client based on osu!.

## Скачать / Download

Откройте **Releases** этого репозитория и выберите нужную версию.

- `ToSU-Trainer-Setup.exe` — установщик, если приложен к релизу.
- `ToSU-Trainer-v0.1.0-win-x64.zip` — автономный пакет игры со встроенным .NET. Для ручной установки распакуйте полностью в новую папку и запустите `trainerSU.exe`.
- `SHA256SUMS.txt` — SHA-256 архива игры.
- `files-manifest.json` — размеры и SHA-256 файлов внутри архива.

**Не скачивайте автоматически созданный GitHub архив Source code для запуска игры.**

## Требования и ограничения

- Windows x64 и совместимый видеодрайвер. Проверка на чистой машине ещё необходима.
- Карты и пользовательские данные не включены.
- Установщик устанавливает в новую папку, а не поверх существующей установки.
- Bongo отключён: Coming soon.
- Мультиплеер требует совместимого сервера протокола v2. Его развёртывание и проверка двух игровых клиентов выполняются отдельно; наличие ZIP не означает готовность онлайн-сервиса.
- Неподписанный EXE может вызвать предупреждение Windows SmartScreen.

Это модифицированный клиент, а не официальный дистрибутив osu!. Лицензия исходного проекта поставляется в архиве как `OSU-LICENCE.txt`.
